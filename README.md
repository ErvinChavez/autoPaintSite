# Park Auto Paint & Body Website

Modern responsive website built for Park Auto Paint & Body using Next.js, TypeScript, and Tailwind CSS.

The site focuses on showcasing real auto body repair work, increasing customer contact, and creating a strong modern online presence for the business.

---

## Features

- Responsive modern UI
- Full-screen hero section
- Before & after gallery
- Services section
- Mobile navigation menu
- Sticky mobile CTA bar
- Click-to-call functionality
- SMS quote button
- Instagram integration
- Optimized for mobile users
- Upgrade-ready structure for future systems

---

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- React Icons
